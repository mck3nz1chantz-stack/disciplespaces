# DiscipleSpaces — In-app tutorial (maintainer summary)

The Help screen (`/help`) loads content from `src/lib/tutorial.ts`. Update that file and this doc together.

## Access

- Header help icon (CircleHelp) → `/help`
- Settings → **Help & tutorial**
- Quick Start row → Help

Works fully offline (bundled copy).

## Sections (current)

1. **What is a Space?** — Living container; Group (5) / Family (10); modes inside one Space.
2. **Living modes** — All · Custom · Guided · Advanced · Freeform; filter history; no Space-per-template.
3. **Members & capacity** — Names only; Family vs Group caps.
4. **Running a session** — Draft starts immediately; Session tab for shared content.
5. **Private notes** — Session ↔ Private tabs; scroll-lock keeps pace with the step you’re on; scroll position preserved; never exported.
6. **Prayer board** — Individual / Group; Request / I prayed / Update; included in Space Updates.
7. **Bible reader & logging** — Offline KJV; log passages into sessions.
8. **Quick Start checklist** — Tappable steps to create / session / Bible / Help.
9. **Light & dark appearance** — Header cycle + Settings picker; localStorage.
10. **Inviting others** — DS1 package / QR; no past sessions with invite.
11. **Backup & Space Updates** — DSX1 export/import; private notes never included.
12. **Privacy & data notes** — Local-first; shared vs private boundary.

## Tone

Calm, short paragraphs, plain language. Prefer “you” and concrete button names from the UI.
