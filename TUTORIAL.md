# DiscipleSpaces — In-app tutorial (maintainer summary)

The Help screen (`/help`) loads content from `src/lib/tutorial.ts`. Update that file and this doc together.

## Access

- Header help icon (CircleHelp) → `/help`
- Settings → **Help & tutorial**
- Quick Start row → Help

Works fully offline (bundled copy).

## Sections (current)

1. **What is a Space?** — Living container; Group (5) / Family (10); modes inside one Space; shared vs private data.
2. **Host vs guest** — Host edits title & people; guests Sync; both Sync after changes.
3. **Living modes** — All · Custom · Guided · Advanced · Freeform; filter history; no Space-per-template.
4. **People list (host only)** — Names only; host adds/removes; guests read-only + Sync.
5. **Room key & Sync** — Host opens room; guests Join once; Sync CTAs; New room key keeps members.
6. **Running a session** — Draft starts immediately; Session tab for shared content.
7. **Private notes** — Session ↔ Private tabs; scroll-lock; never in group room / DSX1.
8. **Prayer board** — Individual / Group; shared via Sync and group files.
9. **Bible reader & logging** — Offline KJV + WEB; log passages into sessions.
10. **Quick Start checklist** — Create/join → meet → share room key.
11. **Light & dark appearance** — Header cycle + Settings picker; localStorage.
12. **Inviting others (host)** — Room key primary; Invite QR; group files offline.
13. **Account Key** — Upload my Spaces / Link & restore; not a group login.
14. **Backup & group files** — DSX1 / DSP1; bookmark production URL.
15. **Privacy & data notes** — Local-first private notes; opt-in shared room.

## Tone

Calm, short paragraphs, plain language. Prefer “you” and concrete button names from the UI.
